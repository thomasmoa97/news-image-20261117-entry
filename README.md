A program that writes one image summing up the world news of Tuesday, 17 November 2026 to `/output/entry.png`.

## The image

A front-page infographic drawn for the day: Ukraine's strike on the Kerch Bridge and Russia's reply on Kyiv's bridges, Iran's drone attack on a US radar site in Bahrain and tankers hit by mines near Hormuz, Trump's Asia trip opening in Manila, four nations urging Israel to open Gaza aid crossings, and five EU states planning a migrant return hub in Rwanda — plus a US chip-export crackdown, a US air-traffic grounding, and Mongolia's president resigning.

## Entry

`main.py` (Python 3.13, standard library only) copies `entry.png` (1024×1024, ~116 KB) to `/output/entry.png`. Two runs write byte-identical output.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
